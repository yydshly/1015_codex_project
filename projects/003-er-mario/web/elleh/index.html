HOW TO PLAY

用熟悉的动作，
探索陌生的世界。

更换角色 / 动作对比
点击左上角角色按钮或按 V；数字 1–7 快速切换。预览中可让七个角色同步跑跳。
移动 / 奔跑
WASD 或方向键；按住 Shift 奔跑。
三段跳
保持移动，在落地后迅速再次按空格，连续衔接三次。
远跳 / 下砸
移动中按住 C 再跳跃；空中按 X 下砸。
蹬墙跳
腾空触墙后迅速再按空格。
镜头 / 交互
拖动画面转镜头，滚轮缩放；靠近地标后按 E。

场景参考《艾尔登法环》艾雷教堂的实机画面，使用重新制作的几何、材质和角色控制。此处没有运行原版游戏或 libsm64。
