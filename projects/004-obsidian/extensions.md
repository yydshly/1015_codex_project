# 可扩展现象、场景与实施路线

星系盘、龙卷、双螺旋和文字聚合已接入原作 GPU 三维碎片系统，其余方向为研究建议。难度为进一步落地的相对工作量判断，不是工时承诺。

## 十二类扩展方向

| 现象 | 输入与主要改造 | 应用场景 | 难度与边界 |
| --- | --- | --- | --- |
| 文字、标志与产品轮廓聚合 | 本页已实现可输入的三维文字；SVG / 模型还需目标加载与匹配 | 品牌首屏、发布会、标题、片尾 | 文字已实现；标志与产品模型仍需接入 |
| 建筑生长与城市重组 | 建筑模型及楼层分组；按基础、主体、顶部安排延迟 | 建筑方案、城市展陈、空间演变 | 中等；视觉搭建不验证受力与施工 |
| 晶体、分形、双螺旋 | 晶格 / 分形 / 参数曲线；分配节点、连接与面密度 | 结构教学、生命科学主题装置 | 中等；真实分子需原子坐标、键型与尺度 |
| 星系、星环与吸积盘 | 螺旋臂 / 圆环 / 轨道；控制半径、角速度、厚度和色彩 | 天文主题、视听演出、片头 | 中等视觉效果；真实演化需引力模型与数值求解 |

| 鸟群、鱼群与迁移 | 路径 / 目标场；个体协同时增加邻域搜索、避障和状态更新 | 自然展陈、群体行为教学、艺术装置 | 进阶；上游群舞没有 Boids 个体交互 |

| 产品爆炸图与零件装配 | 真实零件、装配关系和约束；保留独立拓扑与语义 | 产品展示、培训、维修说明 | 进阶；不能只换采样点，需零件身份和约束 |
| 材料循环与再生 | 资源、产品、拆解和新产品形态；扩展阶段、材质与镜头 | 环保展陈、循环品牌主题、公益传播 | 中等视觉叙事；收支与环境影响需可靠业务数据 |

## 四个三维演示做了什么

| 实验 | 生成规则 | 观察内容 | 未实现部分 |
| --- | --- | --- | --- |
| 星系盘 | 可调 2–7 条旋臂、有厚度盘面、三维朝向 | 旋臂数量、卷曲、整体旋转与聚合 | 引力、恒星质量、轨道演化 |
| 龙卷 | 高度决定半径、螺旋带、差速旋转 | 顶部半径、环绕圈数与聚合 | 空气压力、真实速度场与烟雾 |
| 双螺旋 | 两条管状螺旋与横向连接 | 圈数、半径、三维结构与整体旋转 | 原子、化学键、分子动力学 |
| 文字 | 文字正反面与轮廓采样，边缘沿深度分布 | 最多 8 字输入、厚度、宽度、自由视角 | 字体编辑、任意外部模型和标志导入 |

四者共享原作实际生成的 Voronoi 立体碎片、GPU 状态 MRT、材质、阴影、镜面和后期，支持原作 / 扩展切换、聚合、旋转速度、碎片尺寸、扰动、重组与暂停。目标数量随低 / 中 / 高画质同步，不再使用独立二维点画布。

扩展形态间以 GPU 当前状态快照作为起点进行 1.6 秒过渡；暂停时修改参数直接显示。自由视角支持围绕目标旋转和检查文字厚度。原作录制入口仍针对原作时间线，未为四种扩展提供完整录制流程。

## 推荐实施顺序

### 第一阶段：替换一种形态

从文字或标志开始：

1. 保留原巨石，新增目标生成器。
2. 输出与碎片数量一致的位置、法线、大小和分组。
3. 为细笔画、尖角与轮廓增加采样权重。
4. 选择空间排序规则，检查交叉、突跳与尺度变化。
5. 添加进入、停留、退出阶段，调整镜头保证可读。
6. 验证循环、暂停定位、低画质轮廓与键盘操作。

完成标准：同一批三维碎片稳定往返，目标清楚可读，原位与循环接缝一致；新增参数与资源来源可复现。

### 第二阶段：新增运动现象

优先用螺旋、漏斗、波前等解析函数，继续保持任意时间定位。明确起终点、速度、延迟，并处理离地、遮挡和相机穿越。

若加入依赖历史状态的模拟，则增加固定步长、初始化 / 重置、回放缓存或检查点；原作的直接时间定位不能原样沿用。

### 第三阶段：接入互动输入

将声音、指针或数据映射为有界的聚合度、亮度、尺度或流场强度，平滑跳变。提供输入缺失时的回退、暂停和重置；摄像头与麦克风必须有清晰授权和隐私说明。

### 第四阶段：按场景交付

| 场景 | 除效果外要完成什么 |
| --- | --- |
| 品牌 / 产品网页 | 移动设备预算、封面与延迟加载、文本可读性、减少动态效果 |
| 展馆 / 装置 | 目标硬件实测、长时间运行、超时复位、离线资源、异常恢复 |
| 教学 | 单位、变量、对照实验与解释，区分艺术示意和科学模型 |
| 数据故事 | 数据来源 / 时间、编码说明、标签、筛选、键盘和表格替代 |
| 视频 / 舞台 | 画幅、时长、稳定输出、格式 / 音轨、录制性能和设备支持 |

## 选题优先级

- **先做**：文字 / 标志、螺旋 / 漏斗、参数化结构，与现有采样和时间函数最接近。
- **有明确用途再做**：声音、真实数据与姿态交互，输入流程会成为主要工作。
- **单独立项**：科学流体 / 天体模拟、通用破碎工具、机械装配系统，它们会改变核心状态模型或资产语义。
