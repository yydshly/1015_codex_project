# 能力、价值与适用边界

“已有”指固定提交 `74510f1` 的源码能力；实测操作在 [notes.md](notes.md) 单列。“建议”是本研究基于实现的扩展判断。

## 已有能力

| 能力 | 实际实现与价值 | 边界 | 源码入口 |
| --- | --- | --- | --- |

| Voronoi 碎裂 | 表面分割、折面处理、向内挤出；裂缝与碎片对应 | 表面薄壳，不是完整体积材料断裂 | Fracture，L508–881 |
| 程序化教堂 | 墙面洞口、拱顶、尖塔、飞扶壁与玫瑰窗 | 视觉模型，不验证建筑结构 | Cathedral，L912 |
| 程序化鲸鱼 | 身体截面、鳍部、路径和局部摆动 | 无流体动力学或生物实测模型 | Whale，L1070；SHADERS.whale，L1670 |

## 本研究新增的 GPU 三维能力

| 功能 | 已实现行为 | 接入位置 |
| --- | --- | --- |
| 四种新目标 | 有厚度星系、螺旋带龙卷、管状双螺旋与连接、正反面与侧边组成的立体文字 | extension-shapes.mjs，输出位置 / 尺度与四元数 |
| 同系统渲染 | 沿用原作 Voronoi 合并网格、四张状态纹理、材质、阴影、镜面与后期 | 原 stateFrag 内新增分支，原 shard / depth shader 继续读取同一状态 |
| 连续切换 | GPU 复制当前位置、朝向与材质，1.6 秒过渡到新目标；切换中可再次切换 | extension-system.mjs 的 snapshot / select |
| 通用参数 | 聚合、旋转速度、碎片尺寸、扰动，暂停后修改立即呈现 | uniform 参数与独立时钟 |
| 专属参数 | 旋臂数量 / 卷曲、漏斗半径 / 圈数、螺旋圈数 / 半径、文字厚度 / 宽度 | 参数重采样与范围限制 |
| 三档画质 | 新旧数量之间重采样 GPU 快照，新目标数量与实际碎片数同步 | ShardSystem.use 的 onBundle 钩子 |
| 观察与操作 | 自由镜头、重置视角、恢复参数、散开再聚合、返回原作 | 中文控制桥与共用渲染器 |

这些是本仓库新增能力，不属于固定上游版本。依然是程序化视觉演示，没有引入科学求解器或外部模型导入器。

三期增加 48 秒完整循环：原作 18 秒、四种新形态各 7 秒、回归巨石 2 秒；支持章节定位、拖动时间轴、2 秒 GPU 形态过渡、连续环绕与升降镜头。循环与视频使用相同时间函数和当前四组参数，导出过程中固定所选画质。

视频支持 720p / 1080p、24 / 30 fps，MP4（H.264 / AAC 立体声）和 WebM（VP9 / Opus），含声音开关、音量、进度、取消、恢复预览、成片播放和再次下载。原作合成音效与四种新增声音编成同一个 48 秒音轨，跟随暂停 / 定位 / 速度，试听与导出使用同一音轨。WebCodecs 固定时间戳逐帧编码，设备慢会延长生成时间，不压缩动画。浏览器能力检测显示各格式的声画编码支持；原作 PNG 序列入口保留，本轮未验证 PNG。

## 价值与复用

**视觉表达**：相同碎片为形态切换提供连续性；材质、镜头与音效共同表达资源聚集成产品、个体形成群体、材料循环等主题。

**技术学习**：从 CPU 几何规则到 GPU 状态求值，再到场景与后期，代码提供完整链条。适合研究目标点动画、确定性随机、采样分布和反射 / 阴影一致性。

**实际复用**：优先提取目标生成器、匹配器、运动阶段和渲染表现四个接口。限定少量形态与镜头可服务品牌、展陈与科普示意；产品化还需资产加载、编辑、配置存储、错误提示和设备预算。

## 尚不具备的交付能力

- 任意上传模型后自动生成同等完成度的破碎、匹配与镜头。
- 科学准确的流体、天体、群体行为或守恒求解。
- 全设备固定帧率或每次精确生成 32,000 个碎片。
- 音频输入、真实数据绑定、姿态识别、完整零件装配系统。
- 一次绘制完成整帧；原作独立录制入口的声音行为与本地完整动画导出分开保留。

扩展时所需的数据与工程工作见 [extensions.md](extensions.md)。
