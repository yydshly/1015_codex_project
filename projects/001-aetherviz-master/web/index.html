WHY IT STOPS / 运动结果

查看计算关系与假设

加速段：a = max(0, F/m − μg)。撤力后：a = −μg·sign(v)，到 v = 0 后保持静止；从速度 v 减到零的滑行距离为 d = v²/(2μg)。静止时用同一有效摩擦系数平衡较小推力。

两车：m₁u₁ + m₂u₂ = m₁v₁ + m₂v₂；v₂ − v₁ = e(u₁ − u₂)。墙：v₁ = −eu₁，墙与地球接受反向冲量。e = 0 时两车同速滑行；模型不求接触形变或材料强度。

接触时若仍在施力，立即撤去推力。解析计算接触与停稳时刻，避免跨帧穿透。μ = 0 时只结束观察，速度保留。
