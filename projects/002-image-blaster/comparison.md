# 与既有研究比较：价值落在哪一层

对比依据是本仓库与 `F:/codex_project/1014_codex_project/` 已有研究记录。它们验证范围不同，不据此给出模型性能排行或商业回报评分。摘录来源与快照时间见 [prior-research.md](references/prior-research.md)。

## 对比矩阵

| 项目 | 输入 → 输出 | 核心实现 | 生成阶段的外部模型依赖 | 本地运行与可控性 | 已有验证范围 |
| --- | --- | --- | --- | --- | --- |
| image-blaster | 图片 → 环境、物体、音效、场景 | Claude Skills + API 脚本 + 查看器 | Marble、图片编辑、Hunyuan / Meshy、ElevenLabs | 资产落本地；背景为 splat，物体网格与布局可编辑 | 源码与研究网页，生成待实测 |
| AetherViz Master | 教学主题 → 互动课件代码 | Skill 约束 AI 写 HTML / JS | 写代码时依赖外部 AI；生成课件运行时无需 AI | 逻辑与公式可审查；科学正确性要核验 | 本地三个课件已运行，不是任意主题批量评测 |
| Atlas / 月门水庭 | 参考图 → Blender 脚本与几何 | 本地实验采用 AI 看图写 Blender Python | 参考图由 ImageGen 制作；本实验未用专用图生 3D 服务 | 可编辑 `.blend`、脚本与导出 GLB；细节依赖建模投入 | 本地几何、实际渲染和网页交互已验证 |

| 随机门 | 入口、故事与规则 → 连续偶遇体验 | 本地原创网页、预制内容、随机与记忆 | 原画在制作阶段生成；当前原型运行不调模型 | 六处地点、随机事件、手记和回访可直接设计 | 本地交互验证；留存与情绪效果未证实 |

## 和 Atlas / 月门水庭比：专用模型生成资产 vs 代码建模

这是最接近的三维路线比较。image-blaster 用模型生成视觉丰富的背景与物体，模型决定大量细节；月门水庭实验用 Blender 脚本构建具体几何，修改布局和结构更直接，但自然形体与装饰细节明显简化。两条路线都补全了单图不可见内容，均非精确三维重建。

Atlas 上游本身还支持专用图生三维工具、Blender 脚本和程序几何多条路线；不能把我们选用的脚本实验误写成 Atlas 只能写代码。

可学习的组合：规整建筑和布局采用参数化代码，有机道具采用生成模型；统一尺度、坐标、材质及碰撞后再验收。这是研究建议，不是已经验证的组合系统。

## 和 ancient-rap-battle 比：编排价值取决于返工与检查

二者均不自研底层生成模型，都把复杂创作拆成独立资产。image-blaster 拆成背景、物体与声音；视频流程拆成逐句素材、时间轴、候选版本和剪辑。

古人说唱已有音频相关性与可选嘴部检查，但都是有限筛查，不保证口型；image-blaster 主流程缺少自动视觉、几何一致性验收。两者值得借鉴的是局部重做和来源追溯；完整生产成功率、人工时间与成本仍需实测。

## 和 AetherViz 比：模型写代码 vs 模型直接生成媒体

AetherViz 上游是生成课件的规范，计算和交互由产出的 JavaScript 执行。image-blaster 已提供调用脚本和查看器，三维细节交给媒体生成模型。二者都依赖外部 AI，但可审查的对象不同：前者重点是代码、方程和教学逻辑，后者重点是输入提示、资产、布局及几何质量。

## 和随机门比：资产生产 vs 体验设计

image-blaster 解决初始场景和资产，随机门研究故事、随机分配、回应、经历记录和回访。把生成场景接入体验是可行方向，但图生世界不会自动产生好故事、可解谜题或留存。随机门当前版本以本地原画为主要视觉，保留旧 Three.js 场景；不能描述为六处都是生成式可漫游三维世界。

## 价值判断

| 目标 | 判断 | 下一步需要的证据 |
| --- | --- | --- |
| 研究底层三维算法 | 优先级较低，核心生成外包给模型 | 研究底层模型与表示方法 |
| 学习 AI 资产工程 | 有参考价值，拆分、版本、请求恢复、本地加载均可阅读 | 用一个背景和一个物体检查完整恢复路径 |
| 快速制作场景原型 | 有潜力，但依赖结果与人工修整 | 记录首次成功率、修整时间和坐标对齐问题 |
| 形成独立产品壁垒 | 现有证据不足 | 与手动调用同模型比较总时间、重做次数与验收率 |

不能仅因“调用外部模型”就认定没有价值，也不能把一套调用流程直接认定为高壁垒产品。更有意义的指标是：它是否减少了人工步骤、返工和失败损失，并稳定交付可用资产。
