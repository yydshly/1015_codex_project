# 能力、使用场景与边界

研究版本：`4acb43ba126a12358f71838d1b1a05e856b10eaf`，2026-10-15。

**能力**：场景图 → 静态环境、独立物体、声音与可编辑场景。**原理**：Claude Code 调度脚本调用外部模型，落地资产后由网页组合。**价值**：把对象身份、生成请求与场景实例分开管理，支持独立调整、复用和局部重做。**扩展**：质量验收、辅助布局、成本控制与混合建模，详见 [扩展路线](extensions.md)；这些方向尚未实现。

## 能力拆解

| 阶段 | 输入 | 处理与输出 | 依据 |
| --- | --- | --- | --- |
| 场景理解 | 图片、用户要求 | Claude 观察环境、风格、光照、材质和物体，写每图 JSON，再合并 `image.json` | `image-blast-uncover` |
| 确定物体 | 物体候选清单 | 用户确认后写独立 `object.json`；偏好单个可分离实体，重复物体去重并记录数量估计 | 分析规范 `IMAGE-BLAST.md` |
| 清理背景 | 原图、移除物体清单 | 图片编辑模型在一次请求中移除指定内容，生成 clean plate | `image-blast-plate` |
| 静态环境 | 背景图、扣除物体后的场景文字 | Marble 生成高斯泼溅、碰撞网格、全景和缩略图，下载本地文件 | `generate-world.mjs` |
| 独立模型 | 原图、单个物体描述 | 先编辑出参考图，再由 Hunyuan / Meshy 生成模型和材质 | `generate-single-asset.mjs` |
| 声音 | 根据场景与材质编写的文字描述 | ElevenLabs 输出循环环境音或短音效；非循环音频做静音处理和响度规范 | `fal-elevenlabs-sfx.mjs` |
| 场景交互 | 本地 `.spz`、`.glb`、音频 | 浏览、飞行、抓取、重力和碰撞；编辑平移、旋转、缩放并保存布局 | `WorldViewer.tsx` 等 |
| 资产维护 | 编号文件、请求 JSON | 复用已有参考图、续查任务、版本递增、补下载缺失资产 | `request-metadata.mjs` 等 |

## 适用场景

- 游戏关卡或影视场景的概念原型：尽早观察空间氛围和镜头方向。
- 创意网页场景的初始素材：结合另行开发的故事、规则和交互。
- 多模型资产生产流程的工程研究：学习输入拆分、适配器、状态记录和局部重做。
- 根据单张图片构思空间：结果需人工检查和调整。

上述是基于实现方式的适用性判断，本轮没有测量实际生产效率。

## 必须区分的概念

1. `.spz` 负责环境外观；`world.glb` 的来源字段是 `collider_mesh_url`，它是碰撞几何。不能把整套输出描述为精细、可逐面编辑的传统环境模型。
2. “动态物体”主要指刚体交互。Meshy 默认关闭骨骼与动画；物体会动不等于有角色表演或行为智能。
3. 音效是根据描述预生成的素材，查看器主要在点击、抓取时播放；没有完整的接触材质和碰撞冲量驱动声学系统。
4. 物体分析包含文字性位置证据，默认实例却按网格排列；没有自动恢复原图的全部三维位姿、尺度与相机。
5. 原图不可见部分由模型补全。精密测量、施工、机器人接触或科学仿真需要额外验证。
6. 多个源图的分析合并不等于多视角几何重建；世界脚本默认选择最新可见源图。

## 证据与验证

固定版本文件链接集中保存在 [sources.json](references/sources.json)。本轮已核对源码和研究网页；外部模型生成、资产质量、耗时、价格及接口当前可用性均未实测。网页流程是可交互的讲解，不是运行上游生成系统。
