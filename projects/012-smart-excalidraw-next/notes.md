# 研究笔记

## 2026-10-20 · 研究范围

依据本次讨论，将“适用场景 / 支持输入 / 图表类型 / 实现原理 / 实际边界”整理为可交互的中文网页。固定上游提交 `fd139925b01ab34203510d6afa560aa56fcc3201`，保存 11 份主要源文件与哈希清单。

## 核心理解

1. 输入文字、MD / TXT、图片，交给外部模型组织图形数据。
2. 22 种类型是名称、视觉规范与提示词。相同基础图形可以表达很多业务。
3. 生成的数据保留节点、文字、关系和坐标，可在 Excalidraw 中继续编辑。
4. 箭头优化范围是端点位置，没有完整的全局布局实现。
5. 单次请求只传系统提示和当前输入，没有画布与多轮对话上下文。
6. 本地保存配置与远端生成数据流必须分别说明；README 的“不会上传任何服务器”不能直接当作生成时的数据流结论。
7. 任意业务内容能否转换，取决于读取入口、结构完整度与模型能力。工具能力描述可以被画成图，执行需要独立系统。

## 网页实现

- 轻量静态内容 + React / Excalidraw 画布岛；不引入根目录应用依赖。
- 六个场景分别说明业务目的、输入样例、目标图、使用价值和校验重点。
- 22 类图表提供用途分类、关键词检索、描述范例与核对重点。
- 五步原理对应固定版本源文件；可访问原文与本地快照。
- 真实画布支持编辑、重置与导出；数据来自本研究构造，未调用模型。
- 本地字体和运行依赖随静态页保存，兼容现有 Pages 子路径。
