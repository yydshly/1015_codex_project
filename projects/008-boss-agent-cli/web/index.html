04 / RISK BOUNDARIES
能登录，不等于每个请求都能通过。
风控流程示意 · 不访问平台

    
回放一次响应
项目识别错误后停止当前流程。环境风险还可能触发本地锁，避免重复请求。
“页面恢复”只改变演示本地锁；实际还需要平台重新校验。错误码是项目适配器的分类，非平台全部规则。
等待回放模拟发出 0 次
  1. 选择响应，查看请求、判断与停止的顺序。
试试环境风险 37，再连续回放两次。

    
01
有效凭据 ≠ 服务端放行
Cookie、Token 和浏览器环境建立访问条件，账号权限与平台风控仍然生效。
02
控制请求，不承诺隐身
缓存、节流、数量预算和断点停止约束访问规模，无法给出绝对安全的频率。
03
业务动作要看实际语义
当前 apply 复用立即沟通端点，不能据此确认附件简历已送达或招聘者已读。
