RESEARCH 007 / LIVE SOURCE DEMO

从公开配置，到网页播放。

筛选 awesome-zhuiju-free 中的配置地址，提取 HTTP 采集接口，实测搜索、详情、集数、HLS 清单与视频分片，构建单片源网页 Demo。

已验证的来源

来源链：原仓库 → 小马配置 → 暴风资源。示例上游 ID 为 168380，返回 8 集；首两集已验证媒体数据和浏览器播放。资料名称与年份按第三方接口显示。

本机运行

本页可作为静态研究入口；实时搜片和播放信息需要启动随项目提供的 Python 服务。

python -m pip install -r projects/007-zhuiju-source-demo/requirements.txt
python projects/007-zhuiju-source-demo/server.py --port 8767
打开本机 Demo ↗

验证范围

  • 实时搜索、影片详情与 8 集选集。
  • 首两集 HLS 清单、视频分片和 1080p 解码。
  • 网页播放、暂停、切集、进度跳转和搜索空结果。
  • 第三方源可能失效、超时或缓冲；未进行整部影片的完整观看验证。

服务只监听本机；视频优先由第三方 CDN 直连传输。源码和接口报告保存在研究项目目录。
